# 真实字幕验收

完成日期：2026-10-25（香港时间）。结论：文件选择、读取、检查、导出已在浏览器跑通；8 项真实素材及受控变更验收通过。原有 29 项核心测试的通过记录保留，产品代码本轮未修改。

## 素材和人工核对

使用 Blender 开放电影《Tears of Steel》的[官方英文](https://download.blender.org/demo/movies/ToS/subtitles/TOS-en.srt)与[官方简体中文](https://download.blender.org/demo/movies/ToS/subtitles/TOS-CH.srt)。来源、CC BY 3.0 许可和修改记录见同目录 ATTRIBUTION.md。两份 original 文件保留下载原字节，并以 SHA-256 校验。

英文 76 条、中文 77 条。中文原始文件有大量块内空行，第一条缺编号且结束时间未写毫秒。工具明确报格式异常，没有给出全部通过；但这种不规范排版会造成大量连带提示（231 个错误、78 个待核对），不能理解为 309 个彼此独立的问题。这是当前严格解析方式的易用性限制。

为进一步检查，另存 normalized 副本：修整空白、补首条编号 0 与结束毫秒，不改任何字幕正文含义。独立复核确认 77 条正文均保留，仅 7 行末尾空格被移除。原始文件未覆盖。

规范化后人工核实的真实差异有两处：

- 中文多一条 00:00:04–00:00:06 的片头字幕，英文没有。
- 第 9 条英文开始于 42.200 秒，中文开始于 43.000 秒；结束均为 45.000 秒。

工具给出 75 段对应、原文 1 段未对应、译文 2 段未对应，以及编号从零开始的提醒，和人工核对一致。这里没有根据视频判定哪个版本更正确。

## 受控变更验证

另建明确标注的 aligned-control 副本，去掉中文额外片头，并把第 9 条起点对齐英文。这个人工调整版本只作实验基线，不能称为未经改动的官方字幕。

| 场景 | 预期与实测 |
| --- | --- |
| 未改动的官方文件 | 明确报格式异常；不把部分解析结果当作完整通过 |
| 只规范化排版 | 保留并指出上述真实时间差异 |
| 对齐的双语基线 | 76 段全部对应，无问题提示 |
| 删除第 20 段后重编号 | 定位原文第 20 段未对应，其后 75 段仍正确对应 |
| 第 40 段起止都延后 500 ms | 指出双方第 40 段时间不对应 |
| 清空第 60 段正文 | 指出第 60 段空正文，时间仍对应 |
| 同时加入上面三种变更 | 74 段对应；1 个空正文错误，3 个时间对应待核对项，定位正确 |
| 只改译文意思、保留时间 | 无结构提示，验证工具不能判断语义的边界 |

可复现命令：`node verification/real-subtitles/verify.cjs`（从项目根目录运行）。结果见 results.json。
